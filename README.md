# Voice of Terra ·《相见欢》音频分站

这里托管《相见欢》的凯尔希有声剧情 MP3。阅读与收听请前往 [Voice of Terra 主网页](https://luoul-123.github.io/voice-of-terra-for-arknights/?group=act40side)，浏览器地址会一直留在主站。

音频由维护者在本地合成后按完整小节上传，路径为 `audio/<章节文件名>/<台词序号>.mp3`。这里不运行语音服务，也不保存读者的存档。

Voice of Terra 是非官方同人项目。剧情及角色归鹰角网络及相应权利人所有；AI 合成配音不是游戏官方配音。
